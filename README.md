🌐 **Visita la tienda:** <https://bhalleffort.com>

Tienda online de **BHALLEFFORT**: ropa, recargas, streaming, rosas y acompañamiento estudiantil. Eliges lo que quieres, lo agregas al carrito y **confirmas tu pedido por WhatsApp**. Local en Tabacundo, Ecuador, con sorteo mensual.

---

## Qué tiene

- **Secciones:** Ropa (hombre, mujer, niños y varios), Streaming (video, IA y programas), Recargas (celulares y Ecuabet), Rosas y Estudiantil.
- **Carrito** que arma el mensaje de WhatsApp con tu pedido.
- **Panel de administración** en `/admin/` para subir productos, fotos, banners y cambiar ajustes sin tocar código.
- **Páginas para Google** de cada producto (`/p/...`) y de cada sección (`/c/...`), más `sitemap.xml`. Se vuelven a crear solas cada vez que cambias productos o ajustes.
- Funciona bien en celular y en computadora.

## Cómo se maneja

Todo está explicado paso a paso en la guía: **[GUIA.md](GUIA.md)** (también en PDF: `Guia-BHALLEFFORT.pdf`).

## Archivos principales

| Archivo o carpeta | Para qué sirve |
|---|---|
| `index.html`, `css/`, `js/`, `fonts/`, `img/` | La tienda |
| `productos.json` | Lista de productos |
| `ajustes.json` | Ajustes del sitio (redes, sorteo, datos legales) |
| `admin/` | Panel para manejar la tienda |
| `p/`, `c/`, `sitemap.xml` | Páginas para Google (se generan solas) |
| `tools/build-seo.mjs`, `.github/workflows/seo.yml` | El robot que genera esas páginas |
| `CNAME` | El dominio `bhalleffort.com` |
